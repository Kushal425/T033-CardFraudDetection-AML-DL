## 1. The Core Viva Questions (Whiteboard & Concept Ready)

### Q1: Why do V1–V28 inherently limit feature engineering?
- **PCA Redaction:** The original credit card attributes (merchant category codes, cardholder location, IP address, terminal type, velocity counters) were projected via **Principal Component Analysis (PCA)** by ULB/Worldline to preserve European customer privacy.
- **Lost Semantics:** Because each $V_i$ is a linear combination of unknown original attributes, we cannot construct intuitive semantic feature crosses (e.g., "Amount $\times$ Distance from home"). Arbitrary nonlinear combinations lack physical justification.
- **Mathematical Orthogonality:** Principal components are mathematically orthogonal ($r \approx 0$). Linear transformations, rotations, or whitening on $V_1 \dots V_{28}$ simply rescale already decorrelated axes.
- **Principled Solution:** We restricted our engineering to mathematically and behaviorally grounded transformations:
  1. Compressing the extreme positive skew of `Amount` via $\ln(1 + \text{Amount})$.
  2. Preserving circadian temporal rhythm using continuous trigonometric coordinates ($\sin, \cos$ of $2\pi t / 86\,400$).
  3. Constructing **joint geometric norm features** across the latent space:
     - Vector length $\|\mathbf{V}\|_2 = \sqrt{\sum_{i=1}^{28} V_i^2}$.
     - 3-sigma outlier count $\sum \mathbb{I}(|V_i| > 3.0)$.
     - Peak coordinate excursion $\max_i |V_i|$.
  4. Validation-guided pruning of uninformative components ($V_{22}, V_{23}, V_{25}$), which showed near-zero two-sample Kolmogorov-Smirnov separation in EDA.

### Q2: Derive the EM Algorithm on a Whiteboard.
**Problem Setup:**
We observe legitimate transactions $\mathbf{X} = \{\mathbf{x}_1, \dots, \mathbf{x}_N\} \subset \mathbb{R}^d$. We assume data is generated by $K$ Gaussian components with parameters $\boldsymbol{\theta} = \{\pi_k, \boldsymbol{\mu}_k, \boldsymbol{\Sigma}_k\}_{k=1}^K$.
The marginal likelihood is:
$$p(\mathbf{x} \mid \boldsymbol{\theta}) = \sum_{k=1}^K \pi_k \mathcal{N}(\mathbf{x} \mid \boldsymbol{\mu}_k, \boldsymbol{\Sigma}_k)$$
The observed log-likelihood is:
$$\ln p(\mathbf{X} \mid \boldsymbol{\theta}) = \sum_{n=1}^N \ln \left( \sum_{k=1}^K \pi_k \mathcal{N}(\mathbf{x}_n \mid \boldsymbol{\mu}_k, \boldsymbol{\Sigma}_k) \right)$$
Direct differentiation $\nabla_{\boldsymbol{\theta}} \ln p = 0$ is blocked because the summation is inside the logarithm. We introduce latent 1-of-$K$ indicator vectors $\mathbf{z}_n$.

#### 1. E-Step (Expectation / Responsibilities):
Calculate the posterior probability that component $k$ generated transaction $\mathbf{x}_n$:
$$\gamma_{nk} \equiv P(z_{nk} = 1 \mid \mathbf{x}_n, \boldsymbol{\theta}) = \frac{\pi_k \mathcal{N}(\mathbf{x}_n \mid \boldsymbol{\mu}_k, \boldsymbol{\Sigma}_k)}{\sum_{j=1}^K \pi_j \mathcal{N}(\mathbf{x}_n \mid \boldsymbol{\mu}_j, \boldsymbol{\Sigma}_j)}$$
- *Plain English:* $\gamma_{nk}$ is the "soft assignment" (responsibility) of cluster $k$ for transaction $n$. Each transaction divides its membership weight among the $K$ Gaussians so $\sum_k \gamma_{nk} = 1$.

#### 2. M-Step (Maximization / Parameter Updates):
Using the fixed responsibilities $\gamma_{nk}$, maximize the expected complete-data log-likelihood:
1. Effective cluster weight:
   $$N_k = \sum_{n=1}^N \gamma_{nk}$$
2. Component mixing proportion (prior):
   $$\pi_k^{\text{new}} = \frac{N_k}{N}$$
3. Cluster mean:
   $$\boldsymbol{\mu}_k^{\text{new}} = \frac{1}{N_k} \sum_{n=1}^N \gamma_{nk} \mathbf{x}_n$$
   *(Weighted average of all points, weighted by responsibility)*
4. Cluster covariance:
   $$\boldsymbol{\Sigma}_k^{\text{new}} = \frac{1}{N_k} \sum_{n=1}^N \gamma_{nk} (\mathbf{x}_n - \boldsymbol{\mu}_k^{\text{new}})(\mathbf{x}_n - \boldsymbol{\mu}_k^{\text{new}})^\top$$
   *(Weighted sample covariance about the new mean)*

### Q3: Why is the Log-Likelihood Monotonically Non-Decreasing?
- **The Evidence Lower Bound (ELBO):**
  For any arbitrary distribution $q(\mathbf{Z})$ over the latent states:
  $$\ln p(\mathbf{X} \mid \boldsymbol{\theta}) = \sum_{\mathbf{Z}} q(\mathbf{Z}) \ln \left( \frac{p(\mathbf{X}, \mathbf{Z} \mid \boldsymbol{\theta})}{q(\mathbf{Z})} \right) + D_{\text{KL}}(q(\mathbf{Z}) \parallel p(\mathbf{Z} \mid \mathbf{X}, \boldsymbol{\theta}))$$
- Because the Kullback-Leibler divergence $D_{\text{KL}} \ge 0$, the first term $\mathcal{L}(q, \boldsymbol{\theta})$ is a strict lower bound on the true log-likelihood:
  $$\ln p(\mathbf{X} \mid \boldsymbol{\theta}) \ge \mathcal{L}(q, \boldsymbol{\theta})$$
- **In the E-step:** We set $q(\mathbf{Z}) = p(\mathbf{Z} \mid \mathbf{X}, \boldsymbol{\theta}^{(t)})$. This drives $D_{\text{KL}} = 0$, making the lower bound touch the true log-likelihood:
  $$\mathcal{L}(q^{(t)}, \boldsymbol{\theta}^{(t)}) = \ln p(\mathbf{X} \mid \boldsymbol{\theta}^{(t)})$$
- **In the M-step:** We maximize $\mathcal{L}$ with respect to $\boldsymbol{\theta}$ to get $\boldsymbol{\theta}^{(t+1)}$:
  $$\mathcal{L}(q^{(t)}, \boldsymbol{\theta}^{(t+1)}) \ge \mathcal{L}(q^{(t)}, \boldsymbol{\theta}^{(t)})$$
- Therefore:
  $$\ln p(\mathbf{X} \mid \boldsymbol{\theta}^{(t+1)}) \ge \mathcal{L}(q^{(t)}, \boldsymbol{\theta}^{(t+1)}) \ge \mathcal{L}(q^{(t)}, \boldsymbol{\theta}^{(t)}) = \ln p(\mathbf{X} \mid \boldsymbol{\theta}^{(t)})$$
- **Viva punchline:** "Every EM iteration is guaranteed to never decrease the observed log-likelihood. However, because the likelihood surface is non-convex, it converges to a **local maximum**, not necessarily the global optimum. That is why multi-start k-means initialization (`n_init >= 3`) is necessary."

### Q4: What is the Singularity Problem, and why is `reg_covar` mandatory?
- **The Catastrophe:** If a Gaussian component centers directly on a single transaction $\mathbf{x}_m$ ($\boldsymbol{\mu}_k = \mathbf{x}_m$), the distance term $(\mathbf{x}_m - \boldsymbol{\mu}_k) = \mathbf{0}$.
- As the optimization pushes the component's variance $\sigma_k^2 \to 0$, the determinant $|\boldsymbol{\Sigma}_k| \to 0$.
- In the Gaussian density formula:
  $$\mathcal{N}(\mathbf{x}_m \mid \boldsymbol{\mu}_k, \boldsymbol{\Sigma}_k) \propto \frac{1}{|\boldsymbol{\Sigma}_k|^{1/2}} \to \frac{1}{0} = +\infty$$
- The overall likelihood $\ln p(\mathbf{X}) \to +\infty$. The model collapses into an artificial singularity.
- **The Fix (`reg_covar`):** We enforce a positive-definite floor by adding a small diagonal regularization term:
  $$\boldsymbol{\Sigma}_k^{\text{reg}} = \boldsymbol{\Sigma}_k + \epsilon_{\text{cov}} \mathbf{I}_d$$
  with $\epsilon_{\text{cov}} \in [10^{-6}, 10^{-2}]$. This ensures all eigenvalues $\lambda_i \ge \epsilon_{\text{cov}} > 0$, guaranteeing positive definiteness, preventing numerical division by zero, and stabilizing matrix inversion $\boldsymbol{\Sigma}_k^{-1}$.

### Q5: How many free parameters does each GMM covariance topology have?
Let $d$ be feature dimension and $K$ be number of components.
1. **Full Covariance (`full`):**
   - Means: $K \cdot d$
   - Covariance matrices: $K \cdot \frac{d(d+1)}{2}$ (independent symmetric matrices)
   - Mixing weights: $K - 1$ (sum to 1)
   - Total: $p = K d + K \frac{d(d+1)}{2} + (K - 1)$
2. **Diagonal Covariance (`diag`):**
   - Means: $K \cdot d$
   - Variances: $K \cdot d$ (axis-aligned independent variances)
   - Mixing weights: $K - 1$
   - Total: $p = 2Kd + (K - 1)$
3. **Spherical Covariance (`spherical`):**
   - Means: $K \cdot d$
   - Scalar variances: $K \cdot 1$ ($\sigma_k^2 \mathbf{I}$)
   - Mixing weights: $K - 1$
   - Total: $p = K(d + 1) + (K - 1) = K(d + 2) - 1$
4. **Tied Covariance (`tied`):**
   - Means: $K \cdot d$
   - Shared covariance: $\frac{d(d+1)}{2}$
   - Mixing weights: $K - 1$
   - Total: $p = K d + \frac{d(d+1)}{2} + (K - 1)$

**Concrete Numbers for our $d=31$ Engineered Feature Set:**
- For $K=5$, Diag: $2(5)(31) + 4 = \mathbf{314}$ parameters.
- For $K=12$, Full: $12(31) + 12 \frac{31(32)}{2} + 11 = 372 + 5\,952 + 11 = \mathbf{6\,335}$ parameters.
- For $K=16$, Full: $16(31) + 16(496) + 15 = \mathbf{8\,447}$ parameters.

### Q6: AIC vs. BIC — Which Model Won and Why?
$$\text{AIC} = 2p - 2 \ln \hat{L}, \qquad \text{BIC} = p \ln N - 2 \ln \hat{L}$$
- **Why BIC penalizes more:** For our training sample ($N = 50\,000$), $\ln(50\,000) \approx 10.82$. The complexity penalty coefficient in BIC ($10.82p$) is more than $5\times$ larger than AIC's ($2p$).
- **BIC is dimensionally consistent:** As $N \to \infty$, BIC selects the true data-generating order if it is in the model family. AIC is predictive (minimizes out-of-sample KL divergence) but tends to overfit in large samples by adding redundant components.
- **Our Model Selection Protocol (Dual Evaluation):**
  1. **Unsupervised Criterion ($\arg\min \text{BIC}$):** Selected `full` covariance, $K=16$, $\text{reg}=10^{-6}$ ($\text{BIC} = -2\,003\,181$). In purely unsupervised terms, full covariance captures subtle inter-feature correlations on legitimate data.
  2. **Validation Criterion ($\arg\max \text{Val PR-AUC}$):** Selected `full` covariance, $K=12$, $\text{reg}=10^{-4}$, achieving a massive **$\text{Val PR-AUC} = 0.5797$** (compared to $0.0648$ for $K=16$, which overfits legitimate subclusters and loses anomaly contrast).
- **Viva punchline:** "We report BOTH choices honestly. Unsupervised BIC prefers complex modeling of the legitimate density, but $K=12$ with $\text{reg}=10^{-4}$ achieves superior fraud ranking on the validation split because it leaves genuine fraud excursions in the low-density margins."

### Q7: Why is NLL a valid anomaly score, and when does it FAIL?
- **Contract:** Anomaly score $s(\mathbf{x}) = -\ln p(\mathbf{x})$. Lower probability under the legitimate model produces a larger positive score.
- **When it works:** Transactions with extreme, rare multi-component excursions (e.g. $V_{14} < -7.0, \|\mathbf{V}\|_2 > 10.0$) fall far into the Gaussian tails where $p(\mathbf{x}) \approx 0 \implies -\ln p(\mathbf{x}) \gg 0$.
- **The 4 Fundamental Failure Modes ("Density $\neq$ Fraud"):**
  1. **Unusual Legitimacy (False Positives):** A wealthy customer purchasing a $\$15\,000$ antique at 2 AM is statistically rare ($p(\mathbf{x}) \approx 0$), triggering a high anomaly score, but is completely legal.
  2. **Camouflaged Fraud (False Negatives):** Micro-charges (e.g. $\$2.50$ test probe at an automated vending kiosk) intentionally mimic normal day-to-day card telemetry. They inhabit the mode of the Gaussian density and receive low anomaly scores, slipping past detection.
  3. **Heavy Tails vs. Gaussian Decay:** Real credit card telemetry has severe excess kurtosis (features $V_2, V_7, V_8$ have kurtosis $> 70$). Gaussian densities assume exponential tail dropoff ($\sim \exp(-z^2/2)$), causing normal heavy-tail spending to be unfairly penalized.
  4. **Curse of Dimensionality:** In $d=31$ dimensions, probability mass concentrates in an outer hyperspherical shell (the "empty space" phenomenon). The contrast between central mode density and boundary density weakens.
