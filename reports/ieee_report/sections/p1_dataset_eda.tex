\section{Dataset Quality and Exploratory Data Analysis}
\label{sec:dataset_eda}

This section provides an empirical analysis of the credit card fraud benchmark, covering data integrity, class distributions, temporal dynamics, feature representations, and the statistical validity of the Gaussianity assumption for GMM modeling.

\subsection{Dataset Integrity and Quality Audit}
The raw dataset comprises $284,807$ transaction records and $31$ numeric columns, occupying $67.36\,\text{MB}$ in memory. Every feature is continuous (float64), except for the target binary indicator $\text{Class} \in \{0, 1\}$. 
\begin{itemize}
    \item \textbf{Missing Values:} A systematic sweep confirmed exactly zero missing, null, or undefined values across all $8,829,017$ data cells.
    \item \textbf{Duplicate Analysis:} We identified $1,081$ exact duplicate records ($0.3796\%$ of all transactions), accounting for $1,854$ duplicate rows ($1,822$ legitimate, $32$ fraudulent). Exactly one duplicate group straddled class labels (identical feature values recorded with opposing class assignments), indicating potential record collations or identical micro-authorizations. Following the project configuration protocol, duplicates are retained to reflect raw telemetry conditions.
\end{itemize}

\subsection{Class Imbalance and Chronological Partitioning}
Across the complete dataset, only $492$ transactions are fraudulent, establishing an overall positive prevalence of $0.1727\%$ (1 fraud per 578 legitimate transactions). To prevent temporal data snooping, the dataset is split chronologically into 60\% training, 20\% validation, and 20\% test sets, as detailed in Table~\ref{tab:splits}. 

Notice that the empirical fraud rate fluctuates significantly across chronological periods: $0.2107\%$ in training, dropping to $0.1001\%$ in validation, and settling at $0.1317\%$ in test. This natural temporal fluctuation underscores the hazard of random k-fold cross-validation, which would blend these non-stationary regimes and mask temporal generalization challenges.

\subsection{Amount and Time Feature Dynamics}
The two non-anonymized features display distinctive empirical properties:
\begin{itemize}
    \item \textbf{Transaction Amount:} Legitimate transactions have a mean of $\$88.29$ (median $\$22.00$, standard deviation $\$250.11$, maximum $\$25,691.16$). In contrast, fraudulent transactions exhibit a higher mean of $\$122.21$ but a lower median of $\$9.25$ (maximum $\$2,125.87$). Frauds cluster either in small card-testing authorizations (micro-charges) or elevated cash-out values. Exactly $1,825$ transactions ($0.6408\%$) have an recorded value of $\$0.00$ (pre-authorization card pings). The distribution is extremely heavy-tailed; applying an Interquartile Range (IQR) filter ($Q3 + 1.5 \times \text{IQR}$) on legitimate spending marks $31,862$ transactions ($11.2\%$) as statistical outliers ($>\$184.15$). Consequently, $\ln(1 + \text{Amount})$ log-transformation is vital for stabilizing variance.
    \item \textbf{Temporal Span:} The `Time` feature spans $172,792$ seconds, corresponding to $48.0$ continuous hours (2 calendar days). Aggregating transactions into 1-hour bins reveals clear circadian rhythms: transaction frequency drops between hours 2--6 AM local time and peaks during late afternoon hours. Fraudulent transactions, however, maintain relatively uniform velocity throughout the night, exploiting off-peak periods when manual authorization desks have reduced staffing.
\end{itemize}

\subsection{Feature Discriminative Power and PCA Orthogonality}
Features V1--V28 represent principal components obtained from card transaction metadata. To identify which latent dimensions carry fraud signals, we computed the two-sample Kolmogorov-Smirnov (KS) statistic and Cohen's $d$ effect size between legitimate and fraudulent samples:
\begin{itemize}
    \item \textbf{Top Discriminating Features:} V14 ($\text{KS} = 0.8535, d = 2.318$), V10 ($\text{KS} = 0.8320, d = 1.742$), V12 ($\text{KS} = 0.7996, d = 2.029$), V17 ($\text{KS} = 0.7870, d = 1.587$), and V11 ($\text{KS} = 0.7854, d = 1.998$). For instance, legitimate transactions have a mean V14 value of $+0.098$, whereas fraudulent transactions average $-7.277$, providing strong linear and non-linear separability.
    \item \textbf{PCA Orthogonality:} Correlation analysis across legitimate training observations confirms that off-diagonal pairwise correlations are near zero (maximum $|r| = 0.1451$). Because V1--V28 originate from principal component analysis, near-zero linear correlation is mathematically expected, justifying diagonal covariance structures ($\boldsymbol{\Sigma} = \text{diag}(\sigma_1^2, \dots, \sigma_D^2)$) in initial GMM approximations.
\end{itemize}

\subsection{Gaussianity Audit and GMM Assumptions}
A central prerequisite for Gaussian Mixture Models is that within-cluster distributions conform to multivariate normal densities. We conducted an audit on legitimate training instances ($N = 170,524$) across all 28 PCA dimensions:
\begin{itemize}
    \item \textbf{Normality Rejection:} The Shapiro-Wilk test (evaluated on a standard subsample of $5,000$ points) rejected the null hypothesis of univariate normality for all $28$ features ($p < 0.05$).
    \item \textbf{Heavy Tails and Kurtosis:} While dimensions such as V11 ($\text{skew} = 0.13, \text{kurt} = 0.14$) and V13 ($\text{skew} = 0.14, \text{kurt} = 0.15$) exhibit near-Gaussian moments, extreme leptokurtosis dominates other features: V2 ($\text{kurt} = 114.97$), V7 ($\text{kurt} = 77.01$), and V8 ($\text{kurt} = 261.68$).
    \item \textbf{Implications for Modeling:} Only $9$ out of $28$ features meet mild plausibility criteria ($|\text{skew}| < 1$ and $|\text{excess kurtosis}| < 3$). Single-component Gaussians ($K=1$) cannot accommodate these long, heavy-tailed margins without severely underestimating tail density. This finding motivates multi-component GMMs ($K \ge 3$) capable of assigning separate components to heavy-tail clusters, or non-parametric isolation baselines.
\end{itemize}

\subsection{Dataset Limitations}
We explicitly record four methodological limitations of this benchmark:
\begin{enumerate}
    \item \textbf{Anonymized PCA Projections:} The loss of true semantic labels for V1--V28 precludes root-cause business interpretation (e.g., specific merchant types or geolocation anomalies).
    \item \textbf{Limited Temporal Horizon:} A two-day observation window cannot reflect weekly payroll variations, monthly bill cycles, or prolonged fraud campaign dynamics.
    \item \textbf{Geographic Restriction:} Restricted to European transactions under specific banking protocols from 2013, limiting transferability to contemporary e-commerce payment rails without adaptation.
    \item \textbf{Static Imbalance Ratio:} Base rates vary substantially in production ecosystems, necessitating adaptive threshold recalibration in live deployments.
\end{enumerate}
